
# The Merchant's Hound

**A guiding light for Vikings who have lost their way.**

The Merchant's Hound adds a distinctive green beacon to Haldor, Hildir, and the Bog Witch, making merchants easier to locate while exploring Valheim without a map.

Designed with no-map playthroughs in mind, these beacons provide visible landmarks that help players navigate toward merchants without relying on map markers or external navigation tools.

Whether you're sailing along the coast or wandering through the wilderness, keep an eye out for the green glow!

## Features

- Adds a bright green beacon to Haldor, Hildir, and the Bog Witch.
- Uses Valheim's existing visual effects to create a magical guiding light.
- Provides a visual navigation aid for no-map playthroughs.
- Works automatically without crafting, commands, or additional player interaction.
- Supports dedicated servers without requiring additional client-side installation.
- Can be used in solo play throughs since you are the "server"

## Requirements

**Expand World Prefabs by JereKuusela**

https://valheim.hexium.gg/mods/JereKuusela/Expand_World_Prefabs

The Merchant's Hound is a configuration pack built for Expand World Prefabs (EWP).

It does not contain its own plugin or replace any functionality provided by EWP. All beacon behavior is handled by JereKuusela's mod.

You must have Expand World Prefabs installed for these configurations to work.

## Installation

### Mod Manager

Install The Merchant's Hound and its required dependency using gale mod manager.

### Manual Installation

1. Install Expand World Prefabs and its required dependencies.
2. Download The Merchant's Hound.
3. Extract the included configuration files into your Valheim `BepInEx/config/expand_world/` directory, preserving the supplied file names and folder structure.
4. Start Valheim or restart your dedicated server.

For dedicated servers, install the configuration files on the server.

Players connecting to a properly configured server do not need to install The Merchant's Hound or Expand World Prefabs separately.

## How to Use

Once installed, the beacon system works automatically.

Explore the world as you normally would and watch for the distinctive green light marking a merchant's location.

The following merchants are supported:

- **Haldor**
- **Hildir**
- **The Bog Witch**

The beacons serve as visual landmarks, helping you navigate toward merchants without opening your map.


**Note:** The beacons are intended to assist navigation, not reveal merchant locations on your map or provide automatic directions to them.
